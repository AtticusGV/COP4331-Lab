# COP4331-Lab
Mock repository for the previously made web application for COP4331

The COLORS application allows users to login and register color names to a database that can be searched.

For the lab, a Digitalocean droplet was used, in unison with a domain purchased from Godaddy

SETUP:
1. Set up a Digitalocean droplet
2. Purchase a domain
3. Connect the IP address from the droplet to the domain
4. Upload the provided files to the server
5. Login as root to add users (with a name + password for each)
6. Login as a user to add entries to the database

To run the application, simply enter your domain URL in any browser!

(Provided files were NOT written by me. They were provided in the COP4331 course at UCF. Minor changes to design were made.)
